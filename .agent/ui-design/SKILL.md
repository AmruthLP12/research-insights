# Clash Command UI Design Skill

Use this skill for screens, components, typography, colors, navigation,
and visual refinement.

## Design direction

-   Dark, polished, compact gaming utility.
-   Charcoal and graphite surfaces, restrained warm accent, clear
    semantic status colors.
-   Do not directly copy Clash of Clans screens, logos, or proprietary
    art.
-   Avoid generic dashboard templates, excessive gradients, neon glows,
    and decorative clutter.
-   Make timers and the selected village the primary visual anchors.

## Dashboard priorities

1.  Selected village and village switcher.
2.  Active upgrade slots/builders.
3.  Next completion and remaining time.
4.  Secondary actions: start upgrade, history, settings, village
    management.

## Interaction rules

-   Destructive actions require confirmation.
-   Forms validate inline and preserve user input on errors.
-   Empty states explain what to do next.
-   Notification permission is requested only when the user enables
    notifications or schedules a reminder.
-   Support compact Android screens, large text, readable contrast, and
    sensible touch targets.
-   Do not encode status through color alone; include labels or icons.
